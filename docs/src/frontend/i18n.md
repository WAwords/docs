# 前端国际化(i18n)实现方案

## 什么是国际化

国际化（Internationalization，简称 i18n）是指设计和开发产品、应用程序或文档，使其能够轻松适应不同地区、语言和文化的过程。

## 常见的 i18n 解决方案

### 1. 原生 JavaScript 实现

```javascript
// 语言包
const messages = {
  'zh-CN': {
    welcome: '欢迎',
    hello: '你好，{name}！'
  },
  'en-US': {
    welcome: 'Welcome',
    hello: 'Hello, {name}!'
  }
};

// 当前语言
let locale = 'zh-CN';

// 翻译函数
function t(key, params = {}) {
  let message = messages[locale][key] || key;
  // 替换变量
  for (const [key, value] of Object.entries(params)) {
    message = message.replace(`{${key}}`, value);
  }
  return message;
}

// 使用示例
console.log(t('welcome')); // 欢迎
console.log(t('hello', { name: '张三' })); // 你好，张三！
```

### 2. Vue 项目使用 vue-i18n

#### 安装

```bash
npm install vue-i18n@9
# 或者
yarn add vue-i18n@9
```

#### 配置

```javascript
// src/i18n/index.js
import { createI18n } from 'vue-i18n';

const messages = {
  'zh-CN': {
    nav: {
      home: '首页',
      about: '关于'
    },
    welcome: '欢迎来到我们的网站'
  },
  'en-US': {
    nav: {
      home: 'Home',
      about: 'About'
    },
    welcome: 'Welcome to our website'
  }
};

const i18n = createI18n({
  legacy: false, // 使用 Composition API 模式
  locale: 'zh-CN', // 默认语言
  fallbackLocale: 'en-US', // 回退语言
  messages
});

export default i18n;
```

#### 在 main.js 中引入

```javascript
import { createApp } from 'vue';
import App from './App.vue';
import i18n from './i18n';

const app = createApp(App);
app.use(i18n);
app.mount('#app');
```

#### 在组件中使用

```vue
<template>
  <div>
    <nav>
      <router-link to="/">{{ $t('nav.home') }}</router-link>
      <router-link to="/about">{{ $t('nav.about') }}</router-link>
    </nav>
    <h1>{{ $t('welcome') }}</h1>
  </div>
</template>

<script setup>
import { useI18n } from 'vue-i18n';

const { t, locale } = useI18n();

// 切换语言
function changeLanguage(lang) {
  locale.value = lang;
}
</script>
```

### 3. React 项目使用 react-i18next

#### 安装

```bash
npm install i18next react-i18next
# 或者
yarn add i18next react-i18next
```

#### 配置

```javascript
// src/i18n.js
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

const resources = {
  'zh-CN': {
    translation: {
      welcome: '欢迎',
      hello: '你好，{{name}}！'
    }
  },
  'en-US': {
    translation: {
      welcome: 'Welcome',
      hello: 'Hello, {{name}}!'
    }
  }
};

i18n
  .use(initReactI18next)
  .init({
    resources,
    lng: 'zh-CN',
    fallbackLng: 'en-US',
    interpolation: {
      escapeValue: false // React 已经安全转义
    }
  });

export default i18n;
```

#### 在组件中使用

```jsx
import React from 'react';
import { useTranslation } from 'react-i18next';

function App() {
  const { t, i18n } = useTranslation();

  const changeLanguage = (lng) => {
    i18n.changeLanguage(lng);
  };

  return (
    <div>
      <h1>{t('welcome')}</h1>
      <p>{t('hello', { name: '张三' })}</p>
      <button onClick={() => changeLanguage('zh-CN')}>中文</button>
      <button onClick={() => changeLanguage('en-US')}>English</button>
    </div>
  );
}

export default App;
```

## 最佳实践

### 1. 语言文件组织

```
src/
  i18n/
    index.js
    locales/
      zh-CN/
        index.js
        common.js
        nav.js
      en-US/
        index.js
        common.js
        nav.js
```

### 2. 避免硬编码文本

不要在代码中硬编码文本，而是使用翻译键。

### 3. 支持复数

```javascript
// vue-i18n
const messages = {
  'zh-CN': {
    apple: '0 个苹果 | 1 个苹果 | {count} 个苹果'
  }
};

// 使用
$tc('apple', 0); // 0 个苹果
$tc('apple', 1); // 1 个苹果
$tc('apple', 5); // 5 个苹果
```

### 4. 日期和数字格式化

使用 Intl API 进行日期和数字格式化。

```javascript
// 日期格式化
const date = new Date();
console.log(new Intl.DateTimeFormat('zh-CN').format(date));
console.log(new Intl.DateTimeFormat('en-US').format(date));

// 数字格式化
const number = 1234567.89;
console.log(new Intl.NumberFormat('zh-CN').format(number));
console.log(new Intl.NumberFormat('en-US').format(number));
```

### 5. 语言切换持久化

```javascript
// 从 localStorage 读取语言设置
const savedLocale = localStorage.getItem('locale') || 'zh-CN';

// 保存语言设置
function saveLocale(lang) {
  localStorage.setItem('locale', lang);
}
```
