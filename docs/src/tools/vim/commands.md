# Vim 常用命令

## 模式切换

### 进入命令模式
按 `Esc` 键或 `Ctrl + [` 键

### 进入插入模式
| 命令 | 说明 |
|------|------|
| `i` | 在光标当前位置前插入 |
| `I` | 在当前行首插入 |
| `a` | 在光标当前位置后插入 |
| `A` | 在当前行尾插入 |
| `o` | 在当前行下方插入新行 |
| `O` | 在当前行上方插入新行 |

### 进入可视模式
| 命令 | 说明 |
|------|------|
| `v` | 字符可视模式 |
| `V` | 行可视模式 |
| `Ctrl + v` | 块可视模式 |

## 光标移动

### 基本移动
| 命令 | 说明 |
|------|------|
| `h` | 左移 |
| `j` | 下移 |
| `k` | 上移 |
| `l` | 右移 |

### 单词移动
| 命令 | 说明 |
|------|------|
| `w` | 下一个单词开头 |
| `b` | 上一个单词开头 |
| `e` | 下一个单词结尾 |

### 行移动
| 命令 | 说明 |
|------|------|
| `0` | 行首 |
| `$` | 行尾 |
| `^` | 行首第一个非空字符 |

### 页移动
| 命令 | 说明 |
|------|------|
| `Ctrl + f` | 向下翻页 |
| `Ctrl + b` | 向上翻页 |
| `Ctrl + d` | 向下翻半页 |
| `Ctrl + u` | 向上翻半页 |

### 屏幕移动
| 命令 | 说明 |
|------|------|
| `H` | 移动到屏幕顶部 |
| `M` | 移动到屏幕中间 |
| `L` | 移动到屏幕底部 |

### 文档移动
| 命令 | 说明 |
|------|------|
| `gg` | 移动到文档开头 |
| `G` | 移动到文档结尾 |
| `:n` | 移动到第 n 行（n 为数字） |

## 编辑操作

### 删除
| 命令 | 说明 |
|------|------|
| `x` | 删除光标所在字符 |
| `dd` | 删除当前行 |
| `dw` | 删除一个单词 |
| `d0` | 删除到行首 |
| `d$` | 删除到行尾 |
| `dG` | 删除到文档结尾 |
| `dgg` | 删除到文档开头 |

### 复制
| 命令 | 说明 |
|------|------|
| `yy` | 复制当前行 |
| `yw` | 复制一个单词 |
| `y0` | 复制到行首 |
| `y$` | 复制到行尾 |

### 粘贴
| 命令 | 说明 |
|------|------|
| `p` | 在光标后粘贴 |
| `P` | 在光标前粘贴 |

### 撤销与重做
| 命令 | 说明 |
|------|------|
| `u` | 撤销 |
| `Ctrl + r` | 重做 |

### 替换
| 命令 | 说明 |
|------|------|
| `r` | 替换光标所在字符 |
| `R` | 进入替换模式 |
| `:%s/old/new/g` | 全局替换 old 为 new |
| `:%s/old/new/gc` | 全局替换并确认 |

## 查找与替换

### 查找
| 命令 | 说明 |
|------|------|
| `/pattern` | 向下查找 pattern |
| `?pattern` | 向上查找 pattern |
| `n` | 查找下一个 |
| `N` | 查找上一个 |
| `*` | 查找光标所在单词 |

## 文件操作

| 命令 | 说明 |
|------|------|
| `:w` | 保存文件 |
| `:w filename` | 另存为 filename |
| `:q` | 退出 |
| `:q!` | 强制退出不保存 |
| `:wq` 或 `:x` | 保存并退出 |
| `:e filename` | 打开文件 filename |
| `:r filename` | 读取文件内容到当前光标后 |

## 多窗口操作

| 命令 | 说明 |
|------|------|
| `:sp` 或 `:split` | 水平分割窗口 |
| `:vs` 或 `:vsplit` | 垂直分割窗口 |
| `Ctrl + w + w` | 在窗口间切换 |
| `Ctrl + w + h` | 切换到左边窗口 |
| `Ctrl + w + j` | 切换到下边窗口 |
| `Ctrl + w + k` | 切换到上边窗口 |
| `Ctrl + w + l` | 切换到右边窗口 |
| `:q` | 关闭当前窗口 |
| `:only` | 关闭其他窗口，只保留当前窗口 |

## 其他常用命令

| 命令 | 说明 |
|------|------|
| `.` | 重复上一个操作 |
| `u` | 撤销 |
| `Ctrl + r` | 重做 |
| `:set number` 或 `:set nu` | 显示行号 |
| `:set nonumber` 或 `:set nonu` | 隐藏行号 |
| `:set expandtab` | 将 Tab 转换为空格 |
| `:set tabstop=4` | 设置 Tab 宽度为 4 |
| `:set shiftwidth=4` | 设置缩进宽度为 4 |
| `:set autoindent` | 自动缩进 |
| `:set syntax=on` | 开启语法高亮 |
| `:set wrap` | 自动换行 |
| `:set nowrap` | 取消自动换行 |
