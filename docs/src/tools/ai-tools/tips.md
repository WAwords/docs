# AI 工具使用技巧

## 通用提示词技巧

### 结构化提示词

使用清晰的框架来组织提示词，帮助 AI 更好地理解需求。

```text
角色：你是一位资深前端开发工程师
任务：帮我审查以下代码的性能问题
背景：这是一个 Vue 3 项目，使用了大量 computed 属性
要求：重点关注计算属性和响应式数据的使用
```

### few-shot 提示

在提示词中提供示例，帮助 AI 理解期望的输出格式。

```text
将以下句子改写成更简洁的表达方式：

示例：
输入：我觉得这个东西可能不是很好用
输出：这个工具不太好用

请改写：
输入：我认为这个功能或许存在一定的改进空间
输出：
```

## 代码相关技巧

### 代码审查

```text
请审查以下代码，指出潜在的问题和优化建议：

[粘贴代码]
```

### 代码解释

```text
请用简洁易懂的语言解释以下代码的作用：

[粘贴代码]
```

### 代码翻译

```text
请将以下 JavaScript 代码转换为 TypeScript：

[粘贴代码]
```

## 内容创作技巧

### 文档撰写

```text
请帮我撰写技术文档，要求：
- 语言简洁专业
- 包含使用示例
- 适当使用代码块
- 结构清晰，有目录
```

### 总结归纳

```text
请将以下内容总结为 3-5 个关键要点：

[粘贴长文本]
```

## 常见注意事项

- **明确具体**：越具体的描述往往能得到更准确的回答
- **分步处理**：复杂任务可以拆分成多个小步骤
- **检查验证**：对 AI 返回的结果进行验证，确保准确性
- **迭代优化**：根据输出结果不断调整提示词
